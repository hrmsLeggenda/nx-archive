## 导入与溯源

固定上游提交：`29609cc76a0a79a86473ef1e0980771e94c97640`。SQLite Git blob SHA-1：`a2e1af6f77f8ff5b48bf287b7492ea40343c91ef`。Actions 构建下载固定版本并检查校验值，变化时必须更新来源锁定文件。

仅导出数值、名称和短条件字段，排除描述正文、能力效果正文、鸟语对话、全文索引、通用抓取表格和图片。上游未检测到仓库许可证，不视为整站转载授权。能力效果由原页面链接提供。

缺失值保留 null；不从数据库默认零值猜测成长率。Serenes Forest 的 Mu 与 Mu* 分别对应未应用／应用个人能力，模拟器不自动叠加个人能力。校验差异保留两者数值，不静默覆盖。

## 数据字段

资源独立记录阶段、路线、地点、资源、数量、获取方式、确定性、刷新、解锁、坐标、来源、核对日期和补丁版本。固定宝箱、随机采集池与条件任务分别处理。unknown/null 不代表禁止刷新或无门槛。

时间轴保存章节、截止日期、条件、奖励、来源；截止日期为游戏内月日，不是现实日期。通用支线半随机出现的说明来自玩家测试，精确内部规则仍未确认。
