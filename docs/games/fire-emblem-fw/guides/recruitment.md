# 角色与挖角：凯伊篇首批查询

## 挖角要同时检查哪些条件

名声、支援、出现章节和交涉要求需要一起核对。名声达标不代表角色已经出现；要求材料的角色还要考虑本路线的材料来源。

## 使用这张表的顺序

先看章节，再看名声与支援，最后准备钱或材料。哈尔温的材料需特别留意：参考站指出凯伊篇地图无法直接采集椰枣，应先确认其他取得途径。

其他路线的条件另表维护，避免把凯伊篇门槛误当作通用门槛。
