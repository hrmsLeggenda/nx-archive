# 职业成长与培养方法

平台：Switch 2；补丁版本未确认。职业数据来自社区整理的固定 SQLite 快照。

[进入58职业数据库与模拟器](../database) · [职业成长静态总表](../data/generated/classes)

有效成长率 = 人物基础成长率 + 当前职业成长加成。职业属性加值会影响当前属性，不能作为每级成长加成累计。

选择培养路线时先比较关键属性的有效成长，再查看技能门槛、许可证、参考等级和名望要求。数据库的参考等级字段不等于已经实测的最低转职等级；缺失主要技能不会被当作“无要求”。职业与精通能力保留名称及原页面链接，效果待中文核对。

模拟器计算升级的数学期望，不保证具体周目的随机结果，也不自动考虑个人能力、成长保底、上限与继承。Mu 的个人能力需要特别核对。
