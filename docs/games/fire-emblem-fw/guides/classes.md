# 职业成长速查：初级职业

> 剧透：初级兵种名称与成长修正。这里只收录五个初级职业，不代表全部兵种。

## 如何读成长修正

下面是职业对成长率的修正，单位为百分点，不是角色个人成长率。表中未列的属性不表示不存在；“推荐等级”也不能直接视为硬性最低转职等级。

| 职业 | 主要正向修正 | 主要负向修正 | 参考技能条件 |
| --- | --- | --- | --- |
| 斗士 | HP +10、力量 +10 | 无 | 剑术 / 斧术 / 格斗术任选 D |
| 猎兵 | HP +10、速度 +10、技巧 +10 | 无 | 剑术 / 箭术任选 D |
| 士兵 | HP +10、防守 +10 | 速度 −5 | 枪术 / 斧术任选 D |
| 飞鸵兵 | HP +10、速度 +10 | 无 | 马术 E+；枪术 / 斧术任选 D |
| 诅咒师 | 魔力 +15、魔防 +10 | 力量 −5、防守 −5 | 黑魔术 / 白魔术任选 D |

上述初级职业的参考表记载推荐 Lv5、名声 Lv1。

## 养成判断

以下为本站建议：先以角色的任务定位选择职业，再比较关键属性的修正。只比较成长合计，会掩盖速度损失或魔力提升等差异。完整培养路线还需要角色成长、个人特技与精通奖励，本站尚未录入这些完整数据。

参考：[职业一览](https://cn.fire-emblem-fw.site/classes.html)。
