# 新手入门：先决定路线，再安排养成

> 剧透：仅涉及系统和篇章名称。

## 开始前需要知道什么

第一部有凯伊、迪托利希、赛奥朵拉与蕾达四条主角路线。不同路线的剧情队友与挖角门槛不同；不能直接把一条路线的招募计划套用到另一条。

## 一份可执行的开局清单

以下为本站编排建议，不是游戏的强制顺序：

1. 确定本轮主角，在笔记中记录当前章节和名声等级。
2. 先统计随剧情加入的队友，再用挖角补足队伍功能；招募要求见[挖角指南](./recruitment)。
3. 将想培养的职业所需技能列成表，分清技能要求、职业成长修正和推荐等级，见[职业速查](./classes)。
4. 探索前列出所需素材，按地点类型筛选；不要把未核对的坐标当作路线指引。
5. 每次跨篇章前保留单独存档，记录队伍与任务状态，便于对照后续攻略。
