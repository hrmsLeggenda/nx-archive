# 战争篇准备清单

> 剧透：第二部系统规则。

战争篇没有第一部式的自由行动和世界地图，推进方式以据点准备后进入战斗为主。

## 出击前检查

下列清单是本站对资料的操作化编排：

- **职业**：在据点检查资格考试和当前可用票证，避免进入战斗后才发现职业没调整。
- **加护与设施**：查看加护设置、白鸦栖木和主角专属设施，再决定出击配置。
- **全军训练**：向行军管理官查看本章可执行的训练项目，按队伍短板选择。
- **装备**：逐个查看武器耐久与替换物。参考资料记载有章节自动补给，不能因此忽略出击前检查。
- **存档**：另存一个据点档，保留调整队伍与重新尝试的机会。

本页不列未经游戏实测确认的具体补给数量。

参考：[主线攻略 · 战争篇](https://cn.fire-emblem-fw.site/story.html)。
