# 阶段资源检索

平台：Switch 2；补丁版本未确认。首批录入 4 处地牢、第一部与救世篇共 54 条物品记录。原名便于核对，暂译均有标记。

固定宝箱与随机采集池分别筛选；同地牢不同阶段的内容独立保存。材料属于可能获取的种类，不保证单次探索全部获得。宝箱依来源记录为每主角一次，刷新与开启条件未经游戏内复核。
